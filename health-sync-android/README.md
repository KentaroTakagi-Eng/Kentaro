# Health→Notion（ヘルスコネクト → Notion 自動転送アプリ）

Androidの **ヘルスコネクト** に集まった体重・体脂肪率・消費カロリー・歩数などを、
Notionの **Diet log DB**（ダイエット記録 ~Diet log~）の「その日の行」へ自動で書き込むアプリです。

```
オムロン体重計 → OMRON connect ┐
スマホ/ウォッチの活動量 ─────┼→ ヘルスコネクト → このアプリ（数時間ごと）→ Notion Diet log DB
                               ┘
血圧・習慣チェック・メモ ─────────────────── スマホのNotionで手入力 ─┘
```

## 初期設定（1回だけ）

### 1. Notionのトークンを作る
1. PCまたはスマホのブラウザで https://www.notion.so/profile/integrations を開く
2. 「新しいインテグレーション」→ 名前（例: `Health Sync`）→ 種類「内部」→ 保存
3. 表示された **内部インテグレーションシークレット**（`ntn_...`）をコピー
4. Notionで **Diet log DB** を開き、右上の「…」→「接続」→ 作ったインテグレーションを選ぶ

### 2. OMRON connect をヘルスコネクトにつなぐ
OMRON connect アプリの設定で「ヘルスコネクト」連携をオンにし、体重・体脂肪率の書き込みを許可します。
消費カロリー・歩数は、Fitbit / Googleフィット / スマホの歩数計アプリなどがヘルスコネクトへ書き込んでいれば取得できます
（ヘルスコネクトの「データとアクセス」で確認できます）。

### 3. アプリを入れる
1. GitHubの **Releases → 「Health→Notion 最新版」** から `health-sync.apk` をスマホでダウンロード
2. 開いてインストール（「提供元不明のアプリ」の許可を求められたら許可）
3. アプリを開き、上から順に
   - 「読み取りを許可する」→ ヘルスコネクトで **すべて許可**（「バックグラウンドでのアクセス」も許可）
   - トークンを貼り付け → 「接続テスト」で列一覧が出ればOK
   - 「過去30日を同期」で過去分を取り込み

以降は数時間ごとに自動で同期されます（初期値: 3時間ごと、今日と昨日の2日分）。
新しいAPKを入れるときは、アンインストールせずにそのまま上書きインストールできます。

> 省電力設定の強い機種では自動同期が止まることがあります。止まる場合は、Androidの設定でこのアプリの
> 「バッテリー」を「制限なし」にしてください。

## 同期のルール
- 日付列（`測定日`）がその日の行を探し、なければ新しく作ります（タイトルは `2025.11.14` の形式）。
- 新しく作る行には、BMI計算用に `身長`・`目標体重` を直近の行から引き継ぎます。
- ヘルスコネクトにデータがない項目は書き込みません（手入力した値を空で消すことはありません）。
- 「上書きする」がオンなら、同じ日にすでに値があってもヘルスコネクトの値で更新します。
- 体脂肪率はNotionの%表示に合わせて `20.3%` → `0.203` で保存します。

## カスタマイズ方法（あとから項目を増やす）

### A. 生活習慣・やりたいことを増やす（アプリの変更は不要）
Notionだけで完結します。

1. Diet log DB に列を追加（例: `ストレッチ` をチェックボックス、`読書(分)` を数値）
2. 必要なら「ダイエット記録」ページの **今日の記録** ボタンの⚙から、その列を入力項目に追加
3. グラフにしたい数値列は、DBの「+」→「グラフ」→ X軸 `測定日`（日）、Y軸 その列（平均）

Claude Codeに「Diet log DBに〇〇を追加して、グラフも作って」と頼めば、この作業は代わりに行えます。

### B. ヘルスコネクトの値を別の列に書きたい / 転送をやめたい（アプリの設定だけ）
アプリの「3. 転送する項目 → Notionの列名」で、スイッチのオン/オフと列名を変えて「保存して今すぐ同期」。
Notion側で列名を変えた場合もここを合わせるだけです。

最初から用意している項目:

| 項目 | 初期の列名 | 初期状態 |
|---|---|---|
| 体重 | 体重 | オン |
| 体脂肪率 | 体脂肪率 | オン |
| 消費カロリー（合計） | 消費カロリー | オン |
| 歩数 | 歩数 | オン |
| 活動カロリー | 活動カロリー | オフ |
| 血圧 上 / 下 | 血圧（上） / 血圧（下） | オフ（連携する血圧計を買ったらオン） |
| 安静時心拍数 | 脈拍 | オフ |
| 睡眠時間 | 睡眠時間 | オフ（Notionに数値列を作ってからオン） |

### C. ヘルスコネクトの新しい種類のデータを追加したい（コードを1行）
1. `app/src/main/java/com/kentaro/healthsync/Metrics.kt` の `ALL_METRICS` に1行追加
2. `app/src/main/AndroidManifest.xml` に対応する `READ_...` 権限を1行追加
3. pushすると GitHub Actions が新しいAPKを作るので、上書きインストール → 「読み取りを許可する」

## 開発メモ
- ビルド: `./gradlew assembleDebug`（GitHub Actions `.github/workflows/android.yml` が自動実行）
- 主なファイル
  - `Metrics.kt` … 転送できる項目の定義
  - `SyncEngine.kt` … 同期処理と定期実行（WorkManager）
  - `NotionClient.kt` … Notion API
  - `Settings.kt` / `MainActivity.kt` … 設定と画面
- `app/debug.keystore` は上書きインストール用の固定の開発用署名鍵です（秘密情報ではありません）。
